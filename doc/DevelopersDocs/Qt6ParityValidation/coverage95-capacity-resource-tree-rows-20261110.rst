Numerical capacity and Resource Tree qualification
==================================================

FRC!E113 specifies the number of numerical propagator groups a single Propagate
command can accept. The editor and native parser append groups dynamically.
Setup, integration and publication consume group and state counts rather than
imposing a product-defined numerical group limit. Actual saved missions ran
16 and 128 groups with two spacecraft per group, all nine covered integration
methods, and both independent and synchronized stepping in two GUI profiles.
The original bounds and failed development attempts remain. This does not
qualify resource exhaustion or the physics of all possible force combinations.

All Others!E120 lists 33 original Resource Tree children. Each already admitted
child has actual creation and configuration evidence in the saved headless and
visible cohorts, including both optional optimizer resources in the licensed
runtime. Only that original list is joined; broader clone/rename/delete
requirements and any additional modern resource types are separate.

Admission uses the recorded versions and launches no native test.
