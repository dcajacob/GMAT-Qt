Complete Save resource evidence
===============================

FRC!E132 requires the Save command to save any Resource to a file. The review
joins actual editor transactions, native exports and independent reloads for
all 85 offered resources, plus 17 named script-only types and two OrbitView
aliases. It includes default bodies, standalone and attached Plate resources,
and real MATLAB function and optimizer resources. The singleton MATLAB service
is not a named resource.

Repairs preserve standalone physical model body assignments, external force
settings, stop repeat count, named state noise compensation syntax, and correct
owned plot and thruster descriptors. The two original dependent stop checks
pass. Separate consumer checks verify nondefault colors on referenced
SpacePoints, file interface state, active polyhedral density, attached power,
and other initialized fields. The audit retains every changed or unavailable
descriptor identity and distinguishes authored values from state reconstructed
by providers and commands.

The 185 headless and 186 visible saved passes retain their executed source
versions. The 177 original default-style failure receipts remain intact.
No original assertion, tolerance or row fingerprint changed. Admission
changes only FRC!E132; it does not qualify the entire current build.
