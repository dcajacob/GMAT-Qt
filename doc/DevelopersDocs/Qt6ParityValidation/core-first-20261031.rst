Repair and verification
------------------------

An output flag reused across calls made ordinary midnight render as the preceding
leap second. With no optional flag, a genuine UTC leap instant instead rendered
as ordinary midnight. Both failures were captured on the goal-start library
before editing production code. They affect the timestamp text, not just metadata.

The two string-format overloads now derive local leap status for each conversion,
request the existing detector for UTC Gregorian output even without a caller
pointer, and copy status out when requested. Identity conversions preserve their
numeric epoch and no longer reuse an incoming flag. Uniform formatting without
a requested flag retains its lack of a leap-table dependency. Public interfaces,
object layout, virtual slots and numerical conversion formulas are unchanged.

Four new reusable unattended contracts pass: ResetFlag, ImplicitFlag,
IdentityFlag and UniformNoTable. They record 524 bounded observations. The
unchanged LeapSecondInputs test also passes, retaining its 128 numeric checks at
100 microseconds, 64 label round trips and fourteen rejection checks. One affected
actual-widget SPK epoch integration case passes offscreen: eleven Applies/missions
and 33 independently checked report rows. Its maximum epoch error is about
0.382ms, position error 2.73e-12 km and velocity error 1.20e-14 km/s, within the
original input-specific epoch and state bounds.

Six final current-library checks pass. The native support tests do not need a
window; no visible desktop or physical-GPU qualification is claimed here.
The twelve YukonParallel receipts, LeapSecondInputs' earlier receipt and the
additional direct YukonQP receipt are retained at their original versions. The
time input test was rerun only because its implementation dependency changed;
none of the unchanged QP checks was replayed.

The actual application and dependent libraries were relinked by the normal build.
The retained commands/hashes identify that local build; they are not a controlled
release/install provenance receipt. No executable/shared-library/runtime snapshot
or passing screenshot was copied. The small synthetic SPK generated by the
integration test is retained as numerical evidence.

      -R '^(QtAcceptance\.LeapSecond(ResetFlag|ImplicitFlag|UniformNoTable|IdentityFlag)|QtGui\.LeapSecondInputs)$'
