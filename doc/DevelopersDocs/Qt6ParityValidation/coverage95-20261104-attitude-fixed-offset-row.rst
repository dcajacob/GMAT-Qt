=================================================

The generic source argument is ``B = C R`` and
``-Bdot B^T = C (-Rdot R^T) C^T`` for constant frame-to-body rotation ``C``.
Thus body angular velocity is the same constant rotation of the frame angular
velocity. The implementation obtains the selected frame's basis and derivative
through the ordinary coincident frame interface without an axis/origin-specific
offset path. Each physical frame retains its original independent oracle and
numerical convention; this does not confer universal astronomical approval.
