Owning-source findings and implementation
------------------------------------------

NAIF's kdata_c/ktotal_c contract lists currently furnished kernels and records meta-kernel children; kinfo_c answers loaded membership. Its output strings may be truncated when buffers are too short. The implementation uses those documented native queries, with grow-and-retry handling for an exactly full filename buffer. Sources: https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/kdata_c.html and https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/kinfo_c.html. No numerical/runtime claim is inferred from API documentation.

SpiceOrbitKernelReader StoreCoverageRange previously built its source list from loadedKernels, a requested-name map. A meta-kernel entry alone did not disclose its child SPKs to that path. It now obtains currently loaded SPK filenames from a protected native KEEPER enumerator, preserving native table order and duplicate entries rather than changing priority by furnishing them again. Explicit GetCoverageStartAndEnd/GetCoverageSpans caller lists remain unchanged; this change repairs the global failure-classification envelope source.

SpiceInterface IsLoaded now delegates to native loaded-path resolution. That resolver first tries a recorded path, the requested native separator spelling and existing GMAT search-path resolution with kinfo_c. It then compares current filesystem identity against enumerated KEEPER filenames to recognize aliases while returning KEEPER's actual spelling. GetFullKernelPath uses the same resolver, so a loaded meta-kernel child need not have a wrapper-map entry before coverage can access it. Empty/missing names remain false/empty; native inspection errors are reported and reset through a controlled UtilityException path.

LoadKernel's already-loaded decision now uses the native resolver. A stale requested-name record no longer masks a real native unload/reset, while an already-loaded child/alias is not furnished again simply because its requested spelling is absent from the wrapper map. If the resolver observes an unavailable recorded member, it removes that stale record and notifies the pool revision so dependent caches are ineligible for reuse. Native pool queries do not themselves furnish or unload anything.

The new protected enumeration helper calls ktotal_c/kdata_c, checks native errors/found status and grows filename storage when the returned string exactly fills its buffer. It rejects capacities beyond the native SpiceInt interface rather than returning a truncated path. The unneeded type/source metadata is not used to assert ownership or reconstruct root load history.
