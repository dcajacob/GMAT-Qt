===============================================

PhysicalBody binding validates a default source of the same concrete/body type, rejects incompatible Earth/Luna NAIF IDs and prevents retargeting after the initial selection. It restores the selected native rotation model and hidden physical-model configuration, preserves explicitly supplied numerical physical properties and keeps a separately owned atmosphere value. Live source readers/caches are not adopted. The descriptor is configurable before BeginMissionSequence, is written first through native parameter ordering and is hidden on ordinary empty-descriptor bodies. Native model orientation and ephemeris-source controls retain the default policy; generic analytic-body controls remain available for ordinary user bodies.

SetSourceFile resolves GetPhysicalBodyName rather than the copied resource name. SolarSystem source, source-file, default-SPICE-policy and reset/add routes include physical-model copies while preserving their user-defined registry category. SetSolarSystem validates and stages a corresponding default provider from the incoming context before changing the binding, then refreshes DE descriptor/source data and invalidates readiness; detachment drops the old DE pointer for these copies. Global ephemeris transactions continue to snapshot actual bodies; the new identity itself is not modified by source/file switching.
