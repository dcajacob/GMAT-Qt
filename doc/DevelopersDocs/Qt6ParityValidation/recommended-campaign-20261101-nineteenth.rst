Recommended campaign: retained field meanings reviewed
======================================================

All 634 previously open field meanings in the retained input census have now
been reviewed in 54 explicit source/guide convention groups. All 987 original
identities retain a reviewed or corrupt/nonrendered-metadata disposition; none
was deleted. This exhausts the original field-meaning worklist, not the larger
all-input documentation obligation. The final local contract, All Others!E12,
remains open pending concrete specialist/configured-input completeness.

Coverage remains 923/1,158 requirements (79.7%) and 1,816/2,367 historical scopes
(76.7%). Recovery dispositions remain 158 accepted/59 held, and local contracts

Substantive review
------------------

The 54 groups distinguish named references, files, switches, colors, indices,
physical quantities, dimensionless factors and mode-dependent values. Each
reviewed identity retains its native metadata type, exact active guide rows,
explicit meaning policy and relevant source hashes. The review fails closed on
an unclassified field or unexpected Units text. The largest group contains407
nonquantity selections whose native type and actual Qt getter identify text,
names, paths, switches or lists; referenced quantities and file contents retain
their own units. Polymorphic OrbitView vectors and epoch values are handled
separately rather than inferred from their Object/String metadata types.

Physical/conventional checks include the body rotation day/century factors,
A1 orientation epochs, FOV degree/radian conversions, impulsive delta-V and
reference gravity, station weather units, integrator/ephemeris time steps,
spacecraft areas/mass/coefficients, thrust-angle and transmitter-frequency
polynomials, and covariance component-unit products. The filter deweighting
sigma threshold compares the square root of the position-covariance trace,
so its existing km unit is appropriate. No replacement scientific oracle,
GPU qualification or numerical mission was implied by this documentation review.

Twenty-six Units entries across seven source pages were clarified:

* Nine local aligned/constrained axis-vector components are explicitly
  dimensionless directions.
* Four ephemeris EpochFormat entries describe selectors rather than dates;
  five ephemeris StepSize entries explicitly state seconds.
* The FOV filename is distinguished from degree-valued file contents.
* AbsoluteTol and OLSEInitialRMSSigma distinguish normalized residual units
  from the zero-covariance unit-weight fallback. Each guide row applies to both
  BatchEstimator and BatchEstimatorInv retained records.
* Orbit covariance units explicitly include off-diagonal products and
  dimensionless Keplerian eccentricity, retaining the existing representation
  instructions and other original text.
* Body OrientationEpoch explicitly states GMAT A1 modified Julian days.
* Three OrbitView camera entries distinguish km-valued vectors from object names.

Every source byte outside these declared Units edits, including descriptions,
examples, formulas, defaults, allowed values and identifiers, is preserved.
No application/core source, production Qt C++, CMake, test assertion or GUI case
recipe changed. The existing100-file core-change inventory remains separately
unapproved for technical scrutiny. Protected TimeSystemConverter.cpp and
MinQP.cpp retain their prior hashes.

Concrete remaining gap
----------------------

A comparison of the actual retained Spacecraft selector states with the current
specialist editor source confirms that the old census omitted five selector
families: Attitude, AttitudeDisplayStateType, AttitudeRateDisplayStateType,
AnomalyType and DateFormat. The attitude editor supplies its own factory model
list, four orientation representations and two rate representations; the parent
resource metadata alone does not inventory these controls. Owned axes,
propagator, noise and attitude properties are also merged dynamically.

The next bounded step is to enumerate the specialist/configured fields and
unit conventions for these missing families, check the other construction
families for equivalent dynamic inputs, and complete a concrete completeness
audit. Template-route counts and the reviewed987-record census are not used as
a substitute for that proof. Independent scientific qualification is separate
from E12's documentation requirement and is not being added as an E12 gate.
