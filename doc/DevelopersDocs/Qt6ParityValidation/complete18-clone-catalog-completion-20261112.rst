Remaining clone-catalog routes
==============================

The partial stage ``build/nasa-coverage/complete18-20261112-clone-catalog-completion-v1``
adds direct Resource Tree clone witnesses for Propagator, VF13ad, GmatFunction
and MatlabFunction. Together with the saved lifecycle, user-body, array and
Fmincon evidence, every one of the worksheet's 33 listed resource kinds has
a positive copy witness. The whole-row scope decision and conjunction audit
remain open.

All four new routes pass in headless X11 and the visible desktop profile.
They cover Cancel, independent object identity and edits, undo/redo, Unicode
save/reopen and native mission execution. The propagator case checks two
independent spacecraft against an analytic circular orbit and verifies that
the two setups own different integrators. Function cases verify arithmetic
outputs of 12 and 15, followed by 12 and 24 after editing the copied function's
source path. VF13ad preserves its solver configuration across the clone and
an independent iteration-limit edit.

The MATLAB route exposed a live defect. Invocation used the resource name,
even when FunctionPath selected a differently named .m file. It now resolves
the selected source basename and parent directory. A temporary function
handle protects that callable from a same-named input variable. The additional
name-collision case and the existing canonical MATLAB creation/execution
case pass. Directory-only paths use the resource name.

Nine qualified copy test executions report 27 native missions. Two checks
were repeated because their first collector executable was rebuilt before
archiving. Their original receipts are retained alongside the replacement
passes bound to retained executable bytes. The initial MATLAB failures and
the intermediate directory-query mistake are also retained. MATLAB emits
missing-variable lookup diagnostics during temporary-name reservations,
while the numerical checks complete successfully.

The user has been asked how formation copying should treat member spacecraft.
The existing shared-member opt-in is tested. Automatically duplicating the
member spacecraft would add different behavior. The old worksheet's
unqualified wording does not specify this choice. No row is admitted while
that decision and the complete parent audit are pending. Coverage remains
1,113 of 1,158, with 12 of 18 agreed rows complete.
