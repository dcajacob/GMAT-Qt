Spacecraft model formats and Earth FK5 integration
==================================================

FRR!E46 uses the actual spacecraft chooser, OpenGL preview, Save/reopen and
mission rendering for a mixed-corner POV mesh. Three framebuffers match the
unchanged geometry checks and show both independent endpoint colors. The
original 13 static geometry observations and the existing native 3DS choice and
render pass are reused. FRR!E44 conjoins these two named formats. The initial
X11 launch failure and the subsequent clipped, dim fixture are retained.

FRR!E144 specifies the Earth mean-equator J2000 integration basis. Sixteen
saved native GUI contexts identify the live internal Earth/FK5/MJ2000Eq frame
and the actual numerical integrator and its four arc clocks. Independent
orbital checks and the separately qualified 15-epoch Earth orientation
reduction complete the basis evidence. This does not qualify all force
models or astronomical accuracy for arbitrary frame transformations.

Admission is offline. Original requirements, assertions, tolerances, failures
and all unrelated statuses remain unchanged.
