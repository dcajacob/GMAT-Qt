Retained-evidence admission and verification
--------------------------------------------

The prior global search checked 674 original bound result receipts and 3,587
distinct exact claims. It was preflight only and supplied no scope credit.
It is retained losslessly compressed, about 665 KiB instead of 12.4 MiB. Original
before-campaign/preflight metadata is also preserved in small compressed files.

The reusable recovery verifier now admits receipts from explicitly named original
ledger collections. Every collection's audit, report, receipt and mapping must
match its sealed hashes. Every added receipt context must also match the hash
recorded by that original audit. No arbitrary receipt path is admitted. The
unchanged claim verifier still requires the exact frozen source/reference,
snapshot identity, registered case/command, recorded executable identities,
terminal log, JUnit and all original assertions. Actual visible witnesses must
have native exposure. Every original clause and both declared modes remain
mandatory; no source/reference version is restored or rewritten by this change.

Four new reusable unit contracts exercise legitimate reuse and reject unknown,
duplicate, unsealed or drifted collections and wrong-mode/changed-assertion
substitutions. All previous35 unit tests are unchanged; all 39 pass. All prior
recovery reports were refreshed by rechecking their retained proofs against the
updated auditor identity. This is static evidence verification, with no GMAT
execution. The campaign builder validates the reports and the original36 local
contract qualifications before adding the four accepted rows.

The independent review checks 40 full original clauses across 14 distinct GUI
execution contexts. It also preserves/checks the eight stronger visible native
clauses underlying the two propulsion gaps. Five child-omission checks, a forced
credit attempt with the held CCSDS child and six actual corrupted-plan attempts
are rejected. No new PNG, screenshot, runtime copy, GUI assertion, production
Qt or core edit is introduced. All 98 prior changed core files retain their
separate technical-scrutiny obligation; no scientific/core approval is granted.

The limits of the older grouped resource dialogs remain: some use independently
constructed owners/hidden launchers and bounded observer exposure. Native OS
input, per-widget exposure, current embedded resource-tree routes, arbitrary
body/frame/texture/input domains, independent force/frame/geodetic science,
physical GPU/compositor/platform behavior and NASA's unavailable current private
corpus remain unqualified. Original temporary raw legacy outputs were not
retained, so this review does not invent a fresh raw-file or pixel audit.
