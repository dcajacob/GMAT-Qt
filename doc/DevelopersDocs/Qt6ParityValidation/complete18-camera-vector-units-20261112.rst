Camera object-or-vector unit coverage
=====================================

OrbitView exposes ViewPointReference, ViewPointVector and ViewDirection as
native Object fields, but each also accepts a three-component vector. The
native type inventory alone did not establish coverage of these nine numeric
inputs. The guide specifies kilometres for all three literal-vector roles.

Their captions now show km in Vector mode. Object selection removes that unit
and disables the numeric fields. The test observes all nine components in
vector, object and return-to-vector states and preserves raw components,
pending settings, native objects, source, files, undo and parameter registries.
The original 18 missing-unit observations remain recorded. Nine original
object-mode checks and 54 repaired headless/visible checks pass. No mission or
full regression ran. The frozen reader replays without native execution.

Only the complete field/source-domain conjunction remains before unit-row
admission. Canonical coverage is unchanged at 1,111/1,158 and 10/18 agreed rows.
