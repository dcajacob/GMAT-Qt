==============================================

This stage covers All Others!E160 under the user's accepted rule: preserve

Evidence and scope
------------------

The supplementary worker opens the real Mission Tree context menu, selects a
command template, configures its source, cancels a first draft, and commits the
next draft.  It checks exact source bytes, undo/redo, clean Apply for repeated
insertions, Unicode save/reopen, and native Build.  A separate traversal of
native ``GmatCommand`` objects checks command identity, parent, and If/Else arm
against the visible tree.  These new checks do not execute missions.

There are 91 missing case identities, each checked headlessly and visibly:
seven previously uncovered command families at nine primary positions, all 21
families at five positions around While, Target and Optimize, and all 21
families at seven If/Else positions.  That supplies 525 placement observations
per profile.  The 114 retained primary-position cases cover the other families
in both profiles, including separate plain-If and If/Else variants.  Their
numerical execution results remain qualified at their recorded source versions.
The original accepted command-configuration children and complete command-context
conjunction supply the separate configuration and execution prerequisites.

An If/Else ``Append inside`` action intentionally inserts before its own Else,
in the true arm.  Explicit before/after-Else and before-EndIf checks cover both
arms.  The earlier pilot that expected the false arm is retained as a failed
test expectation; the production behavior was not changed.  The earlier native
label-observer failure is also preserved with its original source archive.

Audit policy
------------

The reader binds each new run to its build source archive, executed case input,
loaded binary identities, native X11 loader evidence, result and emitted proof.
It independently checks saved scripts, native graphs and visible hierarchy.
Damaged-proof controls must reject a missing position, lost undo check, wrong
If/Else arm, and unrelated source mutation.  The ledger extension changes only
E160 and preserves unrelated records.  Ledger replay launches no native tests.

Original protected numerical assertions, tolerances and inputs remain unchanged.
The sole authorized protected-helper delta is the separately recorded ASCII
window-title fix.  Historical title bytes remain available for previous-stage
replay.  No full regression, full-current-build qualification, or additional
scientific approval is claimed.
