The actual mapping defect and its repair
-----------------------------------------

source and its complete legacy guards, but assigned newer ResourceEditor,
SpacecraftOrbit and MainWindow reference hashes to those older executions.
They also promoted normative documents originally marked post-execution into
the runtime reference dictionary. Their new native definition cases pass, but
those cases cannot establish that the older Workflow ran the newer GUI code.

Two new explicit reviewed compositions restore the complete original Workflow
clause from ``legacy-orbit-epoch-five`` and retain every unchanged native clause
from ``orbit-definitions-six`` or ``epoch-definitions-ten``. Nothing is deleted
from an old mapping, receipt or snapshot. Actual old GUI reference hashes stay
attached to the old Workflow execution; the later native cases retain their
own source/runtime identities. Normative documents retain their original
review-only status. No old proof is rebound to the repaired TimeSystemConverter.

The recovery verifier permits this only when each replacement is an exact
whole clause from an original hash-bound ledger mapping for the same source row.
The assertion source/hash, anchors, expected values, facets, scope and legacy
assertion list must equal the base clause. No original reference path may be
dropped. Original normative-only references cannot be promoted or changed.
Every prior receipt collection is declared explicitly and rechecked, and the
complete row is still mandatory in both unattended and visible modes.

This repairs reference provenance; it does not use the limited legacy Workflow
alone to qualify all six Keplerian fields or the whole epoch-format family.
All later native definition witnesses remain required. The two original
Workflow contexts supplement 22 distinct native contexts, forming an explicit
versioned conjunction rather than one current binary.
