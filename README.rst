GMAT Qt desktop preview
=======================

Private tester snapshots of the Qt 6 frontend and related engine work, based
on NASA GMAT. The frozen preview branch is
``codex/stable-qt-preview-20261104``.

`Download preview packages <https://github.com/dcajacob/GMAT-Qt/releases>`_
when a verified Windows or Mac build is published. The package workflow builds
Windows x64, Apple Silicon and Intel Mac variants. Package builds are still
being verified; an empty Releases page means downloads are not ready yet.

See ``TESTING.rst`` for build instructions, testing suggestions and known limits.
The source-versioned NASA acceptance campaign is at 1,052/1,158 original
requirements; full acceptance and scientific qualification remain incomplete.

The original project overview and license remain in ``README.txt`` and
``License.txt``.
