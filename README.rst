GMAT Qt desktop alpha
=====================

GMAT Qt provides a Qt 6 desktop interface and related engine improvements for
NASA's General Mission Analysis Tool. Version 0.1.0-alpha.1 is an early release
candidate for Linux x86_64, Windows x64, and Apple Silicon and Intel Macs.

See ``RELEASE-NOTES.rst`` for scope and known limitations, and ``TESTING.rst``
for build instructions and reporting problems. The Alpha packages workflow
produces review artifacts from the frozen ``codex/alpha-0.1.0`` branch.

The saved acceptance campaign covers 1,121 of 1,158 original requirements.
Those results apply to their recorded source versions. Each alpha package
records its own source commit and targeted validation in
``PACKAGE-VERIFICATION.json``.

The original project overview and license remain in ``README.txt`` and
``License.txt``.
